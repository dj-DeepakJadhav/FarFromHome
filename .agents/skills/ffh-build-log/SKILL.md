# FFH Build Log Enforcement Skill

After every meaningful session or feature implementation:

## Rules:
1. Append an entry to `Docs/BUILD_LOG.md` formatted by date (`YYYY-MM-DD`).
2. Clearly describe:
   - What changed
   - Why it changed
   - The verified outcome or test result.
