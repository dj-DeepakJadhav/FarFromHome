## 3. RETENTION DESIGN: WHY PLAYERS RETURN
1. **The Relatable Personal Goal:** Every euro earned directly funds the player's university tuition fee (250€), creating strong empathy with the immigrant student journey.
2. **Subconscious Language Mastery:** German nouns transition naturally from unfamiliar sounds into muscle-memory actions without feeling like a boring quiz.
3. **The Room as Living Progress:** Seeing the room transform from a barren concrete box into a cozy home with a purring pet creates immense visual reward.
4. **Five-Minute Session Respect:** A full workday arc plays out cleanly in 5–7 minutes, perfectly tuned for mobile attention spans.
