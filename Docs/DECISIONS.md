# Project decisions

## 2026-09-08: README as the project's one-page design brief

**Decision:** Add a concise game design document to the repository README covering the premise, pivot, loop, signature shelf mechanic, narrative choices, progression, art direction, technical constraints and future direction.

**Why:** Contributors, judges and collaborators need a single entry point that explains the current game without relying on stale prototype descriptions or language-learning claims.

**Consequence:** The README links to the canonical hackathon documents and must stay consistent with `Docs/CANONICAL_NUMBERS.md` and `README_HACKATHON.md`.
